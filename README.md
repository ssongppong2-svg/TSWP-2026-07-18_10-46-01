# FORCE (임시 제목)

중학교 1학년 2학기 과학 **「힘」 단원**으로 만든 5 대 5 라운드 전술 FPS입니다. (발로란트식 규칙·화면)
중력 · 탄성력 · 마찰력 · 합력 · 부력 · 작용 반작용을 **포스 패치**로 장착해 교전하고, **합력**으로 기폭 장치 잠금을 풀어 폭탄을 해체합니다.

- 웹 브라우저(크롬·엣지)에서 바로 실행 — 설치 필요 없음
- **혼자**: 플레이어 1명 + AI 봇 9명 / **온라인 작전**: 친구들과 방 코드로 함께 (팀당 5자리, 빈자리는 봇)
- **7라운드 선승 · 6라운드 뒤 공수 교대**: 라운드마다 구매 시간 → 2분 교전. 한쪽이 전멸하면 그 라운드는 바로 끝남 (한 경기 약 12~16분)
- **상점·크레딧**: 처치·해체·라운드 결과로 크레딧을 받아 구매 시간에 `B`로 권총·리볼버·산탄총·기관단총·소총·저격총과 방탄을 삼. 살아남으면 총·방탄 유지
- **타격감**: 명중·헤드샷·처치 표시와 소리, 연속 처치 표시(에이스까지), 처치 기록, 맞은 방향 표시, 라운드 승리·패배 알림
- **발로란트식 화면**: 위 점수판·생존 인원, 왼쪽 위 미니맵(아군이 보고 있는 적은 붉게), 체력·방탄·탄약·크레딧 숫자
- 작전 지역(맵): **포스 바운드** (비 갠 낮 · 젖은 바닥 · 물류 연구 단지) / **과학관** (밝은 전시실 · 국립 힘 과학관). 맵은 `src/sim/maps/`에 추가하면 브리핑 화면에서 고를 수 있음
- **과학 전시물·실험 장비**: 과학관의 진열장(용수철저울·윗접시저울·빗면·진자·부력 비커)·전시 키오스크·부력 수조·푸코 진자, 포스 바운드의 실험 장비와 교범 포스터
- **개념 카드 → 개념 도감 → 개념 점검**: 경기마다 맵 곳곳에 개념 카드 4장이 놓임. 다가가면 도감에 기록되고, 경기가 끝나면 주운 카드로 점검 문제 3개를 풂 (타이틀의 `개념 도감`에서 16개 개념 확인)
- 바디캠 렌즈 효과(왜곡·노이즈·REC)는 기본으로 꺼져 있고 설정에서 켤 수 있음

## 온라인 작전 (친구와 함께)

Claude 아티팩트 링크로 열었을 때, **같은 링크를 연 사람끼리** 서버 없이 실시간으로 연결됩니다.

1. 아티팩트의 **공유**에서 친구를 초대 (claude.ai 로그인 필요)
2. 한 사람이 타이틀의 **온라인 작전 → 방 만들기** → 화면의 **방 코드 4자리**를 친구에게 알려 줌
3. 친구는 같은 링크에서 **온라인 작전 → 코드로 참가**
4. 대기실에서 각자 **소속**(팀당 5명)과 **포스 패치**(팀마다 같은 패치 2기, 먼저 고른 사람 우선)를 고르고 **준비 완료**
5. 방장이 작전 지역·봇 숙련도를 정하고 **작전 개시** — 빈자리는 봇이 채움

- 방장 컴퓨터가 경기를 계산하고(초당 20번 상태 전송), 참가자는 입력을 보냄. 자기 이동·사격은 참가자 화면에서 바로 보여 주고 방장 결과로 맞춤
- 경기 중 `Esc` 메뉴를 열어도 경기는 멈추지 않음. 참가자가 나가면 그 자리는 봇이 대신하고, 방장이 나가면 경기가 끝남
- 같은 브라우저에서 시험할 때는 주소 끝에 `?mp=local`을 붙여 창 두 개로 열면 서로 연결됨

## 작전 규칙

| | 해체팀 (공격) | 포스팀 (수비) |
|---|---|---|
| 라운드 승리 | **폭탄 2기 모두 해체** 또는 **포스팀 전원 제압** | **해체팀 전원 제압** 또는 **2분 방어**(폭탄 폭발) |
| 임무 | 폭탄 앞 `F` → 합력 잠금 해제 | 폭탄 방어, 해체 경보 시 대응 |

- **7라운드를 먼저 이기면 경기 승리**(최대 13라운드). **6라운드가 끝나면 공수 교대** — 크레딧은 800으로, 산 총·방탄은 처음으로
- 라운드마다 **구매 시간 15초**(전·후반 첫 라운드 20초): 시작 구역 장벽 밖으로 못 나가고, `B`로 상점을 열어 삼. 끝나면 2분 교전
- **폭탄 2기**는 라운드마다 A·B 구역 안의 **무작위 칸**에 놓이고 모두에게 보임 (미니맵·점수판 아래 표시)
- 쓰러지면 그 라운드는 아군 시점으로 관전하고, 다음 라운드에 다시 시작
- **포스 바운드** — 북쪽 포스팀 진영, 남쪽 해체팀 진영, A·B 구역은 동서. 비가 그친 낮이라 바닥이 젖어 있음
- **과학관** — 북쪽 관리동(포스팀) · 남쪽 정문 로비(해체팀). 서관 = A 중력·탄성관, 동관 = B 부력·마찰관, 가운데 푸코 진자 아트리움. 전시물이 엄폐물 (유리 진열장의 유리는 총알이 지나감)

### 크레딧 · 상점
| 받는 크레딧 | |
|---|---|
| 처치 | 200 |
| 폭탄 해체 | 300 |
| 라운드 승리 | 3000 |
| 라운드 패배 | 1900 → 2400 → 2900 (연패할수록) |

- 처음 800, 최대 9000. **살아남으면** 총과 남은 방탄이 다음 라운드까지 유지되고, 쓰러지면 기본 권총만 남음
- 상점은 마우스 잠금을 풀지 않고 화면 안 커서로 고르거나 **숫자 키 1~8**로 바로 삼. **이번 구매 시간에 산 것을 다시 누르면 환불**
- 봇도 팀 평균 크레딧을 보고 풀 구매 / 반 구매 / 아끼기(에코)를 정함

### 정보 · 소리 · 지휘
- **미니맵**(왼쪽 위): 지형 · 폭탄 · 아군 · **아군 누군가가 지금 보고 있는 적**(붉은 삼각형, 놓치면 잠시 `?`). `M`을 누르고 있으면 구역 이름이 있는 큰 지도
- 달리면 발소리가 나서 적이 듣는다 (`Shift` 보행·앉아 걷기는 거의 무음). 사격·착지·재장전·패치 작동도 소리를 낸다
- 분대원(봇)은 들은 소리를 **무전**으로 보고한다: 예) `발소리 포착 — A 사이트 · 근거리`
- 마우스 휠 클릭(또는 `H`)으로 **적 보고**: 조준한 곳을 구역 이름과 함께 무전으로 알린다. 분대원이 그쪽을 경계하고 수색한다
- `G`를 누른 채 마우스로 **지휘 명령**: 집결 · 위치 사수 · 지정 지점(조준한 곳) · A 목표 · B 목표 · 자율 교전

### 합력 잠금 해제 (폭탄 해체)
힘 카드 6장 중에서 골라 **합력**을 요구 합력과 일치시키면 잠금이 풀리며 해체가 진행됩니다.
오른쪽(→)은 `+`, 왼쪽(←)은 `−`로 계산합니다. 해체 중 **피격되면 처음부터** 다시 해야 합니다.

## 포스 패치

- 개인 장착: **일반 2 (`C`·`Q`) · 특수 1 (`E`) · 필살 1 (`X`)**
- 패치마다 **팀 내 2기 한정**, **선착순** — 늦게 고르면 팀원이 먼저 가져감
- 필살 패치는 **필살 게이지 100%** 필요 (시간·피해·처치·해체로 충전, 라운드가 바뀌어도 유지)
- 일반·특수 패치는 라운드마다 다시 충전됨

| 등급 | 패치 | 효과 | 과학 개념 |
|---|---|---|---|
| 일반 | 중력 강화장막 | 3초간 반경 5m 투사체를 서서히 정지. 종료 시 낙하 | 중력 |
| 일반 | 탄성판 | 조준 방향으로 고속 도약 (대형 컨테이너 위로도 진입) | 탄성력 |
| 일반 | 합력 강화장치 | 5초간 총기 공격력 +15% (소총 40 → 46, 경량 방탄 상대 몸통 4발 → 3발) | 합력 |

| `R` | 재장전 |
| `1` `2` `3` / 휠 | 주무기 / 보조무기 / 칼 |

> 브라우저 특성상 `Ctrl`+`W`는 탭 닫기로 처리될 수 있습니다. 경기 중에는 탭을 닫기 전에 확인 창이 뜨며,
> **전체 화면**에서는 지원 브라우저(크롬·엣지)가 이 단축키를 게임으로 넘겨 줍니다.

설정에서 마우스 감도, 시야각, 음량, **화면 흔들림 세기**, **조준점(점+선 / 점만 / 없음)**, **바디캠 렌즈 효과**(기본 끔), 그래픽 품질을 바꿀 수 있습니다.

### 그래픽 품질 · 최적화
- 기본값 **자동**: 기기(GPU·CPU 코어·메모리·크롬OS)를 보고 낮음/보통/높음을 고르고, 경기 중 2초마다 프레임을 보며 **해상도를 먼저 자동 조절**, 그래도 30fps가 안 되면 품질을 한 단계 내림
- 낮음: 점광원 2개 · 환경 반사 끔 · 그림자 없음 · 해상도 80%부터 · 가벼운 입체음향 (학교 크롬북·저사양 노트북 30fps 목표)
- 보통: 점광원 4개 · 블룸 대신 등 후광 (일반 노트북 60fps 목표) / 높음: 점광원 6개 · 블룸 · 지형 그림자
- 요원·1인칭 총·폭탄·등은 재질별로 합쳐 그리기 호출을 줄였고, 멀리 있는 요원은 단순 모델로 그림
- 실제 점광원은 카메라 가까운 등에만 배정되고, 나머지 등은 바닥·벽의 빛 웅덩이로 대신함

## 실행하기

[Node.js](https://nodejs.org) 20 이상이 필요합니다.

```bash
npm install
npm run dev      # 개발용 서버 (주소가 터미널에 표시됨)
npm test         # 규칙·맵·봇·CQB 테스트
npm run build    # dist/index.html 한 파일로 빌드
```

`npm run build`로 만든 `dist/index.html`은 **파일 하나에 모든 것이 들어 있어** 인터넷 없이 더블클릭만으로도 실행됩니다
(글꼴만 인터넷이 있을 때 IBM Plex Sans KR · Rajdhani로 표시). 학교 컴퓨터에 이 파일만 복사해 가도 됩니다.

## 직접 고쳐 보기

- **맵 고치기·추가하기**: `src/sim/maps/force-bound.js`·`science-hall.js`의 글자 지도. 한 글자가 2m × 2m 한 칸입니다.
  `#` 벽, `C` 큰 상자(과학관: 키오스크·수조), `c` 작은 상자(과학관: 진열장), `=` 낮은 방벽(과학관: 전시 탁자), `A`/`B` 폭탄, `F`/`D` 시작 위치.
  새 맵은 같은 형식의 파일(지도 · 포스팀 방어 위치 · 해체팀 집결 위치 · 무전 구역 이름 · 개념 카드 자리 · 조명 · 날씨 · 테마)을 만들고 `src/sim/maps/index.js`에 등록하면 됩니다.
  `theme: 'museum'`이면 과학관 모습, `light`는 조명(`day` 밝은 낮 / `museum` 밝은 실내 / 없으면 야간), `weather`는 `rain`(빗줄기) · `wet`(젖은 바닥) · `clear`,
  `sight`는 최대 시야(m), `push`는 해체팀 봇이 진입을 시작하는 시각(초) 범위입니다. 폭탄은 `a`·`b` 구역 칸 중 무작위로 놓입니다.
- **개념 카드·점검 문제**: `src/sim/concepts.js` (개념 설명 · 문제 · 보기 · 정답 · 해설).
  (`npm test`가 두 진영 사이에 직선 저격 시야가 생기지 않았는지도 검사합니다.)
- **밸런스**: 총·방탄·패치 수치와 가격은 `src/sim/data.js`, 라운드(`ROUNDS`)·크레딧(`ECON`)·시간·체력·이동 속도는 `src/sim/constants.js`.
- **봇 숙련도**: `src/ai/bot.js`의 `DIFFICULTY` (신병 · 정규 · 정예).

### 온라인 구조
요원은 "조종자(controller)"가 보내는 입력(intent)으로만 움직입니다. `PlayerController`(키보드·마우스), `BotBrain`(AI),
`RemoteController`(온라인 참가자의 입력)가 있습니다.
- `src/net/protocol.js`: 방장 상태 스냅숏(4KB 이하: 라운드·점수·크레딧·폭탄 위치 포함) · 사건 재생 · 입력 기록(한 번 누르는 동작은 횟수로, 구매는 번호 목록으로) · 경기 계획(사람 자리·패치 2기 제한)
- `src/net/session.js`: 방 코드 · 참가자 목록 · 방장 판별 / `src/net/transport.js`: Claude 아티팩트 room 또는 같은 브라우저 탭(`?mp=local`)
- `tests/net.test.js` · `tests/rounds.test.js`: 지연 100ms를 둔 방장·참가자 동기화, 한 판 전체, 참가자 구매·라운드 결과 전달을 Node에서 검증
