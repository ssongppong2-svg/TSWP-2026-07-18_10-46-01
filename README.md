# 포스 바운드 (FORCE BOUND)

중학교 1학년 2학기 과학 **「힘」 단원**으로 만든 5 대 5 전술 FPS입니다.
중력 · 탄성력 · 합력 · 마찰력을 **포스 패치**로 장착해서 싸우고, **합력**으로 자물쇠를 풀어 폭탄을 해체합니다.

- 웹 브라우저(크롬·엣지)에서 바로 실행 — 설치 필요 없음
- 지금은 **나 1명 + AI 봇 9명** (나중에 온라인 멀티플레이를 붙일 수 있게 구조를 나눠 두었어요)

## 게임 규칙

| | 해체팀 | 포스팀 |
|---|---|---|
| 승리 조건 | 미리 설치된 **폭탄 2개를 모두 해체** | **해체팀 전원 처치** 또는 **2분 버티기**(폭탄 폭발) |
| 할 일 | 폭탄 앞에서 `F` → 합력 자물쇠 풀기 | 폭탄을 지키고, 락픽 경보가 울리면 막기 |

- 맵: **포스 바운드** — 북쪽이 포스팀 진영, 남쪽이 해체팀 진영, 폭탄은 A·B 구역에 하나씩
- 한 번 쓰러지면 그 판에서는 부활하지 않고 동료를 관전해요.

### 합력 자물쇠 (폭탄 해체)
힘 카드 6장 중에서 골라 **합력**을 목표 힘과 똑같이 맞추면 자물쇠가 돌아가며 해체돼요.
오른쪽(→)은 `+`, 왼쪽(←)은 `−`로 계산합니다. 락픽 중에 **총에 맞으면 처음부터** 다시 해야 해요.

## 포스 패치

패치마다 **팀당 2개**씩만 있어서 같은 팀에서 최대 2명까지 가질 수 있고, **먼저 고른 사람이 가져가요(선착순)**.
한 사람은 서로 다른 패치 **2개**를 장착합니다 (`Q`, `E`).

| 등급 | 패치 | 효과 | 과학 개념 |
|---|---|---|---|
| 일반 | 중력 강화장막 | 3초 동안 내 주변(5m)의 모든 투사체를 서서히 멈춤. 끝나면 멈춘 투사체는 바닥으로 떨어짐 | 중력 |
| 일반 | 탄성판 | 바라보는 방향으로 빠르게 도약 (큰 상자 위로도 올라감) | 탄성력 |
| 일반 | 합력 강화장치 | 5초 동안 소총 공격력 +3 (24 → 27) | 합력 |
| 특수 | 마찰 제로 필드 | 조준한 바닥에 6초 동안 마찰력 0 구역 → 적이 미끄러짐 | 마찰력 |
| 필살 | 중력 붕괴 | 조준한 지점으로 반경 8m의 적을 끌어당겨 3초 묶음 (게이지 100% 필요) | 중력 |

## 총기

| 이름 | 종류 | 공격력 | 탄창 |
|---|---|---|---|
| 벡터 R-24 | 소총 (연사) | 24 (머리 ×2) | 25 |
| 뉴턴 P-1 | 권총 (단발) | 20 (머리 ×2) | 12 |

총알은 눈에 보이는 투사체라서 날아가는 시간이 있고, 중력 강화장막에 붙잡힐 수 있어요.

## 조작법

| 키 | 동작 |
|---|---|
| `W A S D` | 이동 |
| `Shift` | 걷기 (발소리 없음) |
| `Space` | 점프 |
| 마우스 / 왼쪽 클릭 | 조준 / 사격 |
| `R` | 재장전 |
| `1` `2` / 휠 | 소총 / 권총 |
| `Q` `E` | 포스 패치 |
| `F` | 폭탄 락픽 시작·그만두기 |
| `1`~`6` | 락픽 중 힘 카드 고르기 |
| `Tab` | 점수판 |
| `Esc` | 일시정지 (설정·조작법) |

## 실행하기

[Node.js](https://nodejs.org) 20 이상이 필요해요.

```bash
npm install
npm run dev      # 개발용 서버 (주소가 터미널에 나와요)
npm test         # 규칙·맵·봇 테스트
npm run build    # dist/index.html 한 파일로 빌드
```

`npm run build`로 만든 `dist/index.html`은 **파일 하나에 모든 게 들어 있어서** 인터넷 없이 더블클릭만으로도 실행돼요
(제목 글꼴만 인터넷이 있을 때 더 예쁘게 나와요). 학교 컴퓨터에 이 파일만 복사해 가도 됩니다.

## 직접 고쳐 보기

- **맵 고치기**: `src/sim/map.js`의 글자 지도를 바꾸면 돼요. 한 글자가 2m × 2m 한 칸입니다.
  `#` 벽, `C` 큰 상자, `c` 작은 상자, `=` 낮은 방벽, `A`/`B` 폭탄, `F`/`D` 시작 위치.
  (`npm test`가 두 진영 사이에 직선 저격 시야가 생기지 않았는지도 검사해 줘요.)
- **밸런스 바꾸기**: 총·패치 수치는 `src/sim/data.js`, 시간·체력·이동 속도는 `src/sim/constants.js`.
- **봇 난이도**: `src/ai/bot.js`의 `DIFFICULTY`.

## 폴더 구조

```
src/
  sim/      게임 규칙 (화면과 분리 — 테스트·나중의 서버에서도 그대로 사용)
    map.js        포스 바운드 맵, 충돌, 레이캐스트
    match.js      한 경기: 총알, 포스 패치, 폭탄·락픽, 승패
    draft.js      포스 패치 선착순 선택 규칙
    lockpick.js   합력 자물쇠 문제 만들기·채점
  ai/bot.js   봇 (길찾기·교전·락픽·패치 사용)
  client/     3D 화면 (three.js), 1인칭 총, 효과, 효과음
  ui/         화면 (타이틀, 팀 선택, 패치 선택, HUD, 락픽, 결과)

```

### 온라인 멀티플레이를 붙이려면
요원은 "조종자(controller)"가 보내는 입력(intent)으로만 움직여요. 지금은 `PlayerController`(키보드·마우스)와
`BotBrain`(AI)이 있고, 같은 형태로 네트워크 조종자를 만들어 서버의 `Match`에 연결하면 됩니다.
