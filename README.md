# FORCE (임시 제목)

중학교 1학년 2학기 과학 **「힘」 단원**으로 만든 5 대 5 라운드 전술 FPS입니다.
**라운드 전술 사격 + 연구소 요원 바디캠 + 공부가 곧 실력** — 세 가지를 하나로 묶었습니다.
중력 · 탄성력 · 마찰력 · 합력 · 부력 · 작용 반작용을 **포스 패치**와 **맵의 힘 장치**로 쓰고, 기폭 장치의 **힘 잠금 문제**를 풀어 폭탄을 해체합니다.

- 웹 브라우저(크롬·엣지)에서 바로 실행 — 설치 필요 없음
- **혼자**: 플레이어 1명 + AI 봇 9명 / **온라인 작전**: 친구들과 방 코드로 함께 (팀당 5자리, 빈자리는 봇)
- **7라운드 선승 · 6라운드 뒤 공수 교대**: 라운드마다 보급 시간 → 2분 교전. 한쪽이 전멸하면 그 라운드는 바로 끝남 (한 경기 약 12~16분)
- **진짜 2층 작전 지역**: 계단·중2층 통로·공중 다리·발코니·창문. 위층에서 내려다보고, 난간 없는 곳에서는 뛰어내림. 탄·시야·길찾기·봇 모두 높이를 계산
- **맵의 힘 장치**: 탄성 발판 · 승강기(도르래/부력) · 지레 셔터 · 마찰 미끄럼틀 · 여럿이 밀면 빨라지는 상자(합력) — 원리대로 움직임
- **공부가 곧 실력**: 보급 시간마다 **보급 점검** 문제(정답 +200 J) · 해체 잠금 문제 **5종** · 한 개념을 2번 맞히면 **숙달** → 관련 패치 재사용 대기 −15%, 그 개념의 해체 잠금은 계산 결과 표시·빠른 해체
- **보급 단말기 · 에너지(J)**: 처치·해체·라운드 결과·보급 점검으로 에너지를 받아 보급 시간에 `B`로 권총·리볼버·산탄총·기관단총·소총·저격총과 보호막을 받음. 살아남으면 장비 유지
- **연구소 요원 바디캠**: 화면 전체가 하나의 계기판 톤 (REC · 요원 식별 · N·J·% 수치 · 모서리 눈금). 렌즈(가장자리 왜곡·필름 노이즈)는 기본으로 약하게 켜져 있고 설정에서 끌 수 있음
- **타격감**: 명중·머리 명중·제압 표시와 소리, 연속 제압 표시, 제압 기록, 맞은 방향 표시, 라운드 승리·패배 알림
- 작전 지역(맵): **포스 바운드** (비 갠 낮 · 물류 연구 단지) / **과학관** (밝은 전시실 · 국립 힘 과학관). 맵은 `src/sim/maps/`에 추가하면 브리핑 화면에서 고를 수 있음
- **과학 전시물·실험 장비**: 과학관의 진열장(용수철저울·윗접시저울·빗면·진자·부력 비커)·전시 키오스크·부력 수조·천창 아래 푸코 진자, 포스 바운드의 실험 장비와 교범 포스터
- **개념 카드 → 개념 도감 → 개념 점검**: 경기마다 맵 곳곳에 개념 카드 4장. 다가가면 도감에 기록되고, 경기가 끝나면 점검 문제 3개. 결과 화면에 **공부 기록**(보급 점검 · 해체 문제 · 힘 장치 · 새로 숙달)

## 온라인 작전 (친구와 함께)

Claude 아티팩트 링크로 열었을 때, **같은 링크를 연 사람끼리** 서버 없이 실시간으로 연결됩니다.

1. 아티팩트의 **공유**에서 친구를 초대 (claude.ai 로그인 필요)
2. 한 사람이 타이틀의 **온라인 작전 → 방 만들기** → 화면의 **방 코드 4자리**를 친구에게 알려 줌
3. 친구는 같은 링크에서 **온라인 작전 → 코드로 참가**
4. 대기실에서 각자 **소속**(팀당 5명)과 **포스 패치**(팀마다 같은 패치 2기, 먼저 고른 사람 우선)를 고르고 **준비 완료**
5. 방장이 작전 지역·봇 숙련도를 정하고 **작전 개시** — 빈자리는 봇이 채움

- 방장 컴퓨터가 경기를 계산하고(초당 20번 상태 전송), 참가자는 입력을 보냄. 자기 이동·사격은 참가자 화면에서 바로 보여 주고 방장 결과로 맞춤
- 힘 장치(셔터·승강기·상자) 상태, 보급 점검 문제·답, 각자의 개념 숙달도 함께 맞춰짐
- 경기 중 `Esc` 메뉴를 열어도 경기는 멈추지 않음. 참가자가 나가면 그 자리는 봇이 대신하고, 방장이 나가면 경기가 끝남
- 같은 브라우저에서 시험할 때는 주소 끝에 `?mp=local`을 붙여 창 두 개로 열면 서로 연결됨

## 작전 규칙

| | 해체팀 (공격) | 포스팀 (수비) |
|---|---|---|
| 라운드 승리 | **폭탄 2기 모두 해체** 또는 **포스팀 전원 제압** | **해체팀 전원 제압** 또는 **2분 방어**(폭탄 폭발) |
| 임무 | 폭탄 앞 `F` → 힘 잠금 문제를 풀어 해체 | 폭탄 방어, 해체 경보 시 대응. 지레 셔터·승강기로 길을 끊고 위층에서 내려다보기 |

- **7라운드를 먼저 이기면 경기 승리**(최대 13라운드). **6라운드가 끝나면 공수 교대** — 에너지는 800 J로, 받은 장비는 처음으로
- 라운드마다 **보급 시간 15초**(전·후반 첫 라운드 20초): 시작 구역 장벽 밖으로 못 나가고, `B`로 보급 단말기를 열어 장비를 받고 보급 점검 문제를 풂. 끝나면 2분 교전
- **폭탄 2기**는 라운드마다 A·B 구역 안의 **무작위 칸**(2층일 때도 있음)에 놓이고 모두에게 보임 (미니맵·위 점수판 아래 표시)
- 쓰러지면 그 라운드는 아군 시점으로 관전하고, 다음 라운드에 다시 시작
- **포스 바운드** — 북쪽 포스팀 진영, 남쪽 해체팀 진영. A 화물 창고(2층 높이 홀 + ㄷ자 중2층 통로), 중앙 광장 위 공중 다리, B 컨테이너 야드(철제 통로), 2층 연구동
- **과학관** — 북쪽 관리동(포스팀) · 남쪽 정문 로비(해체팀). 서관 = A 중력·탄성관, 동관 = B 부력·마찰관, 가운데 천창 아래 푸코 진자 아트리움(2층 발코니 · 유리 다리), 계단식 강당. 전시물이 엄폐물 (유리 진열장의 유리는 총알이 지나감)

### 에너지 (J) · 보급 단말기
| 받는 에너지 | J |
|---|---|
| 처치 | 200 |
| 폭탄 해체 | 300 |
| 라운드 승리 | 3000 |
| 라운드 패배 | 1900 → 2400 → 2900 (연패할수록) |
| 보급 점검 정답 | 200 (사람만, 라운드마다 한 문제) |

- 처음 800 J, 최대 9000 J. **살아남으면** 총과 남은 보호막이 다음 라운드까지 유지되고, 쓰러지면 기본 권총만 남음
- 보급 단말기는 마우스 잠금을 풀지 않고 화면 안 커서로 고르거나 **숫자 키 1~8**로 바로 받음. **이번 보급 시간에 받은 것을 다시 누르면 반납**
- 오른쪽 **보급 점검**: 아직 숙달하지 않은 개념부터 한 문제. 보기를 누르면 바로 채점·해설
- 봇도 팀 평균 에너지를 보고 풀 보급 / 반 보급 / 아끼기(에코)를 정함

### 힘 잠금 (폭탄 해체)
힘 카드 6장 중 몇 장을 골라 문제가 요구하는 힘을 만들면 잠금이 돌아가며 해체됩니다. 빨리 풀수록 빨리 해체됩니다.
오른쪽·위쪽은 `+`, 왼쪽·아래쪽은 `−`로 계산하고, 해체 중 **피격되면 처음부터** 다시 해야 합니다.

| 잠금 | 개념 | 문제 |
|---|---|---|
| 합력 잠금 | 합력 (반대 방향) | 요구 합력이 보임 — 카드의 합을 맞춤 |
| 마찰 브레이크 잠금 | 힘의 평형 | 걸려 있는 마찰력과 합력 0이 되게 |
| 용수철 잠금 | 용수철저울 | 용수철상수 × 늘일 길이 = 필요한 힘 (직접 계산) |
| 부력 잠금 | 부력의 크기 | 공기 중 무게 − 물속 무게 = 부력 (직접 계산, 위쪽) |
| 달 중력 잠금 | 달에서의 무게 | 지구 무게 ÷ 6 (직접 계산, 위쪽) |

### 공부가 곧 실력 — 개념 숙달
- 보급 점검 · 해체 잠금 · 경기 뒤 점검에서 **한 개념을 2번 맞히면 숙달** (이 브라우저에 저장, 온라인에서도 내 숙달이 적용)
- 숙달한 개념의 **포스 패치는 재사용 대기 −15%** (패치 장착 화면에 ★와 줄어든 시간이 보임)
- 숙달한 개념의 **해체 잠금은 계산 결과가 바로 보이고 0.6배 시간에 돌아감**
- 타이틀의 **개념 도감**에서 개념마다 숙달도(1/2 · ★ 숙달)를 볼 수 있음

### 정보 · 소리 · 지휘
- **미니맵**(왼쪽 위): 층별 지형 · 폭탄 · 아군 · **아군 누군가가 지금 보고 있는 적**(붉은 삼각형, 놓치면 잠시 `?`). `M`을 누르고 있으면 구역 이름이 있는 큰 지도
- 달리면 발소리가 나서 적이 듣는다 (`Shift` 보행·앉아 걷기는 거의 무음). 사격·착지·재장전·패치·셔터·승강기도 소리를 낸다
- 분대원(봇)은 들은 소리를 **무전**으로 보고한다: 예) `발소리 포착 — A 사이트 · 근거리`
- 마우스 휠 클릭(또는 `H`)으로 **적 보고**: 조준한 곳을 구역 이름과 함께 무전으로 알린다. 분대원이 그쪽을 경계하고 수색한다
- `G`를 누른 채 마우스로 **지휘 명령**: 집결 · 위치 사수 · 지정 지점(조준한 곳) · A 목표 · B 목표 · 자율 교전

## 포스 패치

### 그래픽 품질 · 최적화
- 기본값 **자동**: 기기(GPU·CPU 코어·메모리·크롬OS)를 보고 낮음/보통/높음을 고르고, 경기 중 2초마다 프레임을 보며 **해상도를 먼저 자동 조절**, 그래도 30fps가 안 되면 품질을 한 단계 내림
- 낮음: 점광원 2개 · 환경 반사 끔 · 그림자 없음 · 해상도 80%부터 · 가벼운 입체음향 (학교 크롬북·저사양 노트북 30fps 목표)
- 보통: 점광원 4개 · 블룸 대신 등 후광 (일반 노트북 60fps 목표) / 높음: 점광원 6개 · 블룸 · 지형 그림자
- 요원·1인칭 총·폭탄·등은 재질별로 합쳐 그리기 호출을 줄였고, 멀리 있는 요원은 단순 모델로 그림
- 실제 점광원은 카메라 가까운 등에만 배정되고, 나머지 등은 바닥·벽의 빛 웅덩이로 대신함

## 실행하기

[Node.js](https://nodejs.org) 20 이상이 필요합니다.

```bash
npm install
npm run dev      # 개발용 서버 (주소가 터미널에 표시됨)
npm test         # 규칙·2층 맵·힘 장치·해체 문제·숙달·봇·온라인 테스트
npm run build    # dist/index.html 한 파일로 빌드
```

`npm run build`로 만든 `dist/index.html`은 **파일 하나에 모든 것이 들어 있어** 인터넷 없이 더블클릭만으로도 실행됩니다
(글꼴만 인터넷이 있을 때 IBM Plex Sans KR · Rajdhani로 표시). 학교 컴퓨터에 이 파일만 복사해 가도 됩니다.

## 직접 고쳐 보기

- **맵 고치기·추가하기**: `src/sim/maps/force-bound.js`·`science-hall.js`의 글자 지도. 한 글자가 2m × 2m 한 칸이고, 층이 둘입니다.
  - `layout`(1층): `#` 벽, `w` 창문 벽, `C` 큰 상자(과학관: 키오스크·수조), `c` 작은 상자(과학관: 진열장), `=` 낮은 방벽(과학관: 전시 탁자), `a`/`b` 구역 바닥, `A`/`B` 폭탄, `F`/`D` 시작 위치, `^ v < >` 계단(화살표 쪽으로 2층까지 오름)
  - `upper`(2층, 높이 3.6m): `-` `=` 바닥판, `a` `b` 구역 바닥판, `o` 난간 없는 바닥판(뛰어내리는 곳), `#`·`w` 2층 벽·창문, `c` `C` 바닥판 위 상자 — 그 밖의 2층 가장자리에는 난간이 저절로 생김
  - `roofs`: 지붕을 덮는 건물 사각형 / `devices`: 힘 장치(`pad` · `lift` · `gate` · `slide` · `crate`)
  - 새 맵은 같은 형식의 파일(지도 · 포스팀 방어 위치 · 해체팀 집결 위치 · 무전 구역 이름 · 개념 카드 자리 · 장치 · 조명 · 날씨 · 테마)을 만들고 `src/sim/maps/index.js`에 등록하면 됩니다.
  `theme: 'museum'`이면 과학관 모습, `light`는 조명(`day` 밝은 낮 / `museum` 밝은 실내 / 없으면 야간), `weather`는 `rain`(빗줄기) · `wet`(젖은 바닥) · `clear`,
  `sight`는 최대 시야(m), `push`는 해체팀 봇이 진입을 시작하는 시각(초) 범위입니다. 폭탄은 `a`·`b` 구역 칸 중 무작위로 놓입니다.
- **개념 카드·점검 문제**: `src/sim/concepts.js` (개념 설명 · 문제 · 보기 · 정답 · 해설).
  (`npm test`가 두 진영 사이에 직선 저격 시야가 생기지 않았는지도 검사합니다.)
- **밸런스**: 총·보호막·패치 수치와 가격은 `src/sim/data.js`, 라운드(`ROUNDS`)·에너지(`ECON`)·개념 숙달(`MASTERY`)·시간·체력·이동 속도는 `src/sim/constants.js`, 힘 장치는 `src/sim/devices.js`.
- **해체 잠금 문제**: `src/sim/lockpick.js` (문제 종류 · 상황 문장 · 카드 배분).
- **봇 숙련도**: `src/ai/bot.js`의 `DIFFICULTY` (신병 · 정규 · 정예).

### 온라인 구조
요원은 "조종자(controller)"가 보내는 입력(intent)으로만 움직입니다. `PlayerController`(키보드·마우스), `BotBrain`(AI),
`RemoteController`(온라인 참가자의 입력)가 있습니다.
- `src/net/protocol.js`: 방장 상태 스냅숏(라운드·점수·에너지·폭탄 위치·힘 장치 상태·보급 점검 포함) · 사건 재생 · 입력 기록(한 번 누르는 동작은 횟수로, 보급은 번호 목록으로, 점검 답은 번호로) · 경기 계획(사람 자리·패치 2기 제한·개념 숙달)
- `src/net/session.js`: 방 코드 · 참가자 목록 · 방장 판별 / `src/net/transport.js`: Claude 아티팩트 room 또는 같은 브라우저 탭(`?mp=local`)
- `tests/net.test.js` · `tests/rounds.test.js`: 지연 100ms를 둔 방장·참가자 동기화, 한 판 전체, 참가자 구매·라운드 결과 전달을 Node에서 검증
