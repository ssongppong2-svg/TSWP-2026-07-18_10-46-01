# 포스 바운드 (FORCE BOUND)

중학교 1학년 2학기 과학 **「힘」 단원**으로 만든 5 대 5 전술 FPS입니다.
중력 · 탄성력 · 마찰력 · 합력 · 부력 · 작용 반작용을 **포스 패치**로 장착해 교전하고, **합력**으로 기폭 장치 잠금을 풀어 폭탄을 해체합니다.

- 웹 브라우저(크롬·엣지)에서 바로 실행 — 설치 필요 없음
- 현재는 **플레이어 1명 + AI 봇 9명** (온라인 멀티플레이를 붙일 수 있게 규칙과 화면을 분리해 둠)
- 진지한 작전 톤: 바디캠 렌즈(왜곡·노이즈·비네팅), 어두운 야간 시설, 빛번짐, 총구 화염, 반동 패턴, 피격 시 조준 흔들림, 체력이 낮을수록 화면·소리 악화

## 작전 규칙

| | 해체팀 | 포스팀 |
|---|---|---|
| 작전 성공 | 사전 설치된 **폭탄 2기 모두 해체** | **해체팀 전원 제압** 또는 **2분 방어**(폭탄 폭발) |
| 임무 | 폭탄 앞 `F` → 합력 잠금 해제 | 폭탄 방어, 해체 경보 시 대응 |

- 맵: **포스 바운드** — 북쪽 포스팀 진영, 남쪽 해체팀 진영, 폭탄은 A·B 구역에 1기씩
- 전투 불능이 되면 그 판에서는 복귀하지 않고 아군 시점으로 관전

### 합력 잠금 해제 (폭탄 해체)
힘 카드 6장 중에서 골라 **합력**을 요구 합력과 일치시키면 잠금이 풀리며 해체가 진행됩니다.
오른쪽(→)은 `+`, 왼쪽(←)은 `−`로 계산합니다. 해체 중 **피격되면 처음부터** 다시 해야 합니다.

## 포스 패치

- 개인 장착: **일반 2 (`C`·`Q`) · 특수 1 (`E`) · 필살 1 (`X`)**
- 패치마다 **팀 내 2기 한정**, **선착순** — 늦게 고르면 팀원이 먼저 가져감
- 필살 패치는 **필살 게이지 100%** 필요 (시간·피해·처치·해체로 충전)

| 등급 | 패치 | 효과 | 과학 개념 |
|---|---|---|---|
| 일반 | 중력 강화장막 | 3초간 반경 5m 투사체를 서서히 정지. 종료 시 낙하 | 중력 |
| 일반 | 탄성판 | 조준 방향으로 고속 도약 (대형 컨테이너 위로도 진입) | 탄성력 |
| 일반 | 합력 강화장치 | 5초간 소총 공격력 +3 (24 → 27) | 합력 |
| 일반 | 작용·반작용 도탄 | 6초간 탄이 벽·바닥에서 1회 반사 (위력 85%) | 작용·반작용 |
| 일반 | 부력 방패 | 전방에 떠 있는 방탄판 전개 (내구도 220, 10초) | 부력 |
| 특수 | 마찰 제로 필드 | 지정 지점 반경 5m 마찰력 0 구역 6초 → 적 제동 불가 | 마찰력 |
| 특수 | 탄성 그물 | 지정 지점 반경 3.5m 적을 1.2초 구속 후 바깥으로 튕겨냄 | 탄성력 |
| 특수 | 무게 감지기 | 반경 28m 적 위치를 4초간 벽 너머까지 아군에 표시 | 무게 |
| 필살 | 중력 붕괴 | 지정 지점으로 반경 8m 적을 끌어당겨 3초 구속 | 중력 |
| 필살 | 합력 폭주 | 생존 아군 전원 소총 공격력 +3, 8초 | 합력 |
| 필살 | 마찰 폭풍 | 지정 지점 반경 9m 고마찰 구역 7초 → 적 이동 70% 감소, 점프 불가 | 마찰력 |

## 화기

| 이름 | 종류 | 공격력 | 탄창 | 비고 |
|---|---|---|---|---|
| 벡터 R-24 | 소총 (연사 600RPM) | 24 (머리 ×2) | 25 | 연사 시 고정 반동 패턴 |
| 뉴턴 P-1 | 권총 (반자동) | 20 (머리 ×2) | 12 | |
| 전술 나이프 | 근접 | 베기 50 / 찌르기 80 | — | 후방 공격 ×1.5 |

탄은 눈에 보이는 투사체라 비행 시간이 있고, 중력 강화장막에 붙잡히거나 부력 방패에 막힙니다.
정조준·앉기 시 탄 퍼짐과 반동이 줄고, 이동·도약 중에는 크게 벌어집니다.

## 조작법

| 키 | 동작 |
|---|---|
| `W A S D` | 이동 (가속·감속 관성 있음) |
| `Shift` | 보행 (발소리 차단) |
| `Ctrl` | 앉기 (정확도↑, 피탄 면적↓) |
| `Z` / `V` | 좌 / 우 기울이기 (벽에 막히면 그만큼만) |
| `Space` | 도약 |
| 좌클릭 | 사격 · 칼: 베기 |
| 우클릭 | 정조준 (확대) · 칼: 찌르기 |
| `R` | 재장전 |
| `1` `2` `3` / 휠 | 소총 / 권총 / 칼 |
| `C` `Q` `E` `X` | 포스 패치 (일반 · 일반 · 특수 · 필살) |
| `F` | 폭탄 해체 개시·중단 |
| `1`~`6` | 해체 중 힘 카드 선택 |
| `Tab` | 전황판 |
| `Esc` | 일시 중지 (설정·조작 교범) |

> 브라우저 특성상 `Ctrl`+`W`는 탭 닫기로 처리될 수 있습니다. 경기 중에는 탭을 닫기 전에 확인 창이 뜨며,
> **전체 화면**에서는 지원 브라우저(크롬·엣지)가 이 단축키를 게임으로 넘겨 줍니다.

설정에서 마우스 감도, 시야각, 음량, **화면 흔들림 세기**, **바디캠 렌즈 효과**, 그래픽 품질을 바꿀 수 있습니다.

## 실행하기

[Node.js](https://nodejs.org) 20 이상이 필요합니다.

```bash
npm install
npm run dev      # 개발용 서버 (주소가 터미널에 표시됨)
npm test         # 규칙·맵·봇·CQB 테스트
npm run build    # dist/index.html 한 파일로 빌드
```

`npm run build`로 만든 `dist/index.html`은 **파일 하나에 모든 것이 들어 있어** 인터넷 없이 더블클릭만으로도 실행됩니다
(글꼴만 인터넷이 있을 때 IBM Plex Sans KR · Rajdhani로 표시). 학교 컴퓨터에 이 파일만 복사해 가도 됩니다.

## 직접 고쳐 보기

- **맵 고치기**: `src/sim/map.js`의 글자 지도. 한 글자가 2m × 2m 한 칸입니다.
  `#` 벽, `C` 큰 상자, `c` 작은 상자, `=` 낮은 방벽, `A`/`B` 폭탄, `F`/`D` 시작 위치.
  (`npm test`가 두 진영 사이에 직선 저격 시야가 생기지 않았는지도 검사합니다.)
- **밸런스**: 총·패치 수치는 `src/sim/data.js`, 시간·체력·이동 속도는 `src/sim/constants.js`.
- **봇 숙련도**: `src/ai/bot.js`의 `DIFFICULTY` (신병 · 정규 · 정예).

## 폴더 구조

```
src/
  sim/      게임 규칙 (화면과 분리 — 테스트·향후 서버에서도 그대로 사용)
    map.js        포스 바운드 맵, 충돌, 레이캐스트
    agent.js      요원 이동(관성·앉기·기울이기)과 판정 위치
    match.js      한 경기: 탄, 근접, 포스 패치, 폭탄·해체, 승패
    draft.js      포스 패치 선착순·등급별 장착 규칙
    lockpick.js   합력 잠금 문제 생성·채점
  ai/bot.js   봇 (길찾기·교전·정조준·반동 제어·해체·패치 사용)
  client/     3D 화면 (three.js): 맵, 전술 요원 모델, 1인칭 장갑·총, 바디캠 후처리, 효과, 효과음
  ui/         화면 (타이틀, 브리핑, 패치 장착, HUD, 해체 창, 결과)
tests/      node 테스트 (봇끼리 실제 경기도 진행)
```

### 온라인 멀티플레이를 붙이려면
요원은 "조종자(controller)"가 보내는 입력(intent)으로만 움직입니다. 지금은 `PlayerController`(키보드·마우스)와
`BotBrain`(AI)이 있고, 같은 형태로 네트워크 조종자를 만들어 서버의 `Match`에 연결하면 됩니다.
